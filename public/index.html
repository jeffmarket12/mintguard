🛡 MintGuard

A read-only pre-mint checker for BSC free-mint contracts. It inspects public on-chain data before you sign anything — it never signs, never sends a transaction, and never asks for a key.

Try: Flaggies NFT (verified, sold out) · WBNB (verified ERC-20)

MintGuard checks what can be checked from public data: bytecode presence, Sourcify source verification, ABI, owner, token metadata, and a static simulation of the mint call. A SAFE_TO_REVIEW verdict means the checks found no problem — it is not a promise that minting is safe. Verified code can still contain a backdoor. Always read the source yourself before signing.


API: POST /api/check with {"contract":"0x...","function":"mint","args":[1]}. Source: github.com/jeffmarket12/mintguard.
